# 26.03

This release focuses on the technical dept and allowing users to have more agency by making the admin tools available.

## Users

A new habilitation called `ADMIN_TOOLS` was added. It allows a user with a
profile where the abilitation is set to use the admin tools. These tools were
previously only available through the `admin` user configured in the
configuration file for NumaHOP.

## Developers

The package id and artifact id for numahop were changed from `fr.progilone` to
`org.numahop` and `pgcn` to `numahop`. That make it so the full package uri is
now `org.numahop.numahop`.

A few fixes for the `justfile` where the setup rule for building the initial
docker image was added. And the maven environement variable was not passed down
corectly. 

A new sub rule named `exec` was added to the `docker` rule. It allows to run a
command inside an image directly like: `just d exec nh ls`

## Administrators

NumaHOP SpringBoot version was updated from `3.0.2` to `3.5.12`. This is the
latest `3.x` version available to date. The upgrade to version `4.x` is much
more involved. This needed minor code changes and the upgrade is not a breaking
change.

NumaHOP was vulnerable to an exploit with its default configuration due to all
the SpringBoot acutators endpoints being enabled by default. These are now
disabled in the default configuration only keeping the `healh` and `info`. One
way to check if you are vulnerable is to `curl
<instance-url>/actuator/heapdump` if you are able to download the file please
upgrade or add the following to your `application.yml`:

<!-- i18n:skip-start -->
```yaml
management:
    endpoints:
        web.exposure.include: [health, info]
```
